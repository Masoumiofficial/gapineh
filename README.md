# گپینه — صفحهٔ فروش محصول

صفحهٔ فروش فارسی و راست‌چین برای افزونهٔ **گپینه — چت هوشمند و پشتیبانی آنلاین
وردپرس** (محصول اتحاد وردپرس، نسخهٔ ۱٫۰٫۰).

این صفحه در مخزن `Masoumiofficial/gapineh` نگهداری می‌شود و جایگزین صفحهٔ فعلی
`etehadwp.com/gapineh/index.html` است. یک سایت استاتیک است: بدون build، بدون
فریم‌ورک، بدون وابستگی خارجی.

## اجرای محلی

```bash
python3 -m http.server 8080
# سپس http://localhost:8080/
```

مهم: صفحه را با `file://` باز نکنید؛ فونت WOFF2 و مسیر دارایی‌ها به درخواست HTTP
نیاز دارند.

## ساختار مخزن

```
index.html                  ← تنها صفحه؛ همهٔ متن‌ها در HTML سرو می‌شوند
assets/
  css/main.css              ← سیستم طراحی، RTL، ماکت‌های رابط
  js/app.js                 ← تعامل‌ها (تب، منو، پیش‌نمایش، جای‌گذاری قیمت)
  js/config.js              ← تنها فایل اطلاعات تجاری (قیمت، لینک خرید، پشتیبانی)
  fonts/vazirmatn-persian.woff2
  img/                      ← نشان، فاوآیکون، تصویر OG
  img/screenshots/          ← محل اسکرین‌شات‌های واقعی (خالی تا تهیه)
docs/
  EVIDENCE.md               ← جدول قابلیت‌ها با سند و وضعیت تأیید
  AUDIT-CURRENT-LANDING.md  ← ممیزی صفحهٔ فعلی و استخراج هویت بصری
  REFERENCE-ANALYSIS.md     ← الگوهای اقتباس‌شده از صفحهٔ مرجع و دلیل هر کدام
  IMAGE-PLAN.md             ← نقشهٔ تصاویر، اسکرین‌شات‌های لازم، پرامپت‌های مفهومی
  CONFIG.md                 ← اطلاعات تجاری موردنیاز مالک محصول
  DEPLOY.md                 ← استقرار روی هاست و چک‌لیست پس از انتشار
  QA-REPORT.md              ← تست‌های اجراشده، اجرانشده و ایرادهای باز
tools/
  qa/check_static.py        ← QA استاتیک (ساختار، SEO، کنتراست، CSS)
  qa/test_dom.mjs           ← تست رفتاری با jsdom
  qa/run_all.sh
  make_brand_assets.py      ← ساخت og-cover و آیکون‌ها (اختیاری)
gapineh.1.0.0.zip           ← بستهٔ افزونه؛ مرجع راستی‌آزمایی، نه بخشی از سایت
```

## اصول محتوایی

1. **هر ادعا سند دارد.** قابلیت‌ها با کد نسخهٔ ۱٫۰٫۰ تطبیق داده شده‌اند
   (`docs/EVIDENCE.md`). آنچه سند نداشت، در صفحه به‌عنوان قابلیت نیامده است.
2. **هیچ دادهٔ ساختگی.** بدون قیمت ساختگی، بدون شمارنده، بدون امتیاز، بدون نظر،
   بدون نشان اعتماد جعلی، بدون «X فروش».
3. **محدودیت‌ها پنهان نمی‌شوند.** هزینهٔ API، ارسال داده به سرویس مدل، تفاوت با
   تیکتینگ و نبود واتس‌اپ/اینستاگرام در صفحه آمده‌اند.
4. **ماکت از اسکرین‌شات جدا است.** ماکت‌ها با CSS ساخته و برچسب‌گذاری شده‌اند؛
   قاب اسکرین‌شات واقعی تا نبودن تصویر خالی می‌ماند.
5. **دسترس‌پذیری و RTL اصولی:** `lang="fa" dir="rtl"`، ویژگی‌های منطقی CSS
   (`padding-inline-start`، `inset-inline`)، مسیر فوکوس مشخص، `prefers-reduced-motion`.

## پیش از انتشار

- [ ] `assets/js/config.js` را با قیمت و لینک خرید واقعی پر کنید (`docs/CONFIG.md`).
- [ ] سه اسکرین‌شات واقعی را اضافه کنید (`docs/IMAGE-PLAN.md`).
- [ ] `canonical` و `og:url`/`og:image` را با دامنهٔ نهایی تطبیق دهید.
- [ ] `python3 tools/qa/check_static.py` و `node tools/qa/test_dom.mjs` را اجرا کنید.
- [ ] چک‌لیست پس از استقرار در `docs/DEPLOY.md` را در مرورگر واقعی انجام دهید.

  این صفحه.
- کد این صفحه بخشی از پروژهٔ گپینه (اتحاد وردپرس) است. مجوز کد افزونه
