### دستورهای اجرا

```bash
# تست‌های استاتیک (نیازمند Python 3 + html5lib + tinycss2)
python3 -m pip install --user html5lib tinycss2
python3 tools/qa/check_static.py

# تست رفتاری DOM (نیازمند Node.js 18+)
npm install --no-save jsdom
node tools/qa/test_dom.mjs

# اجرای هر دو
bash tools/qa/run_all.sh
```

## ۲. آنچه اجرا **نشد** (و در این گزارش ادعا نمی‌شود)

- **مرورگر واقعی:** Chromium/Firefox در محیط ساخت در دسترس نبود و نصب آن ممکن نشد.
  بنابراین رندر شدن CSS، چیدمان واقعی، سرریز متن‌ها و رفتار لمسی **به‌صورت چشمی
  تأیید نشده‌اند**. تست DOM تنها رفتار منطقی و وضعیت ARIA را می‌سنجد.
- **Lighthouse / PageSpeed Insights:** اجرا نشد. هیچ امتیاز یا CWVای در این گزارش نیست.
- **axe / WAVE:** اجرا نشد. بررسی دسترس‌پذیری محدود به بررسی ساختاری، برچسب فرم‌ها،
  وضعیت ARIA، کنتراست محاسبه‌شده و مسیر فوکوس در کد است.
- **تست مرورگرهای قدیمی (Safari، مرورگرهای ایرانی):** انجام نشد.
- **بررسی HTTP لینک‌های خارجی:** محیط ساخت به‌جز چند دامنهٔ محدود، دسترسی شبکه‌ای
  ندارد؛ بنابراین لینک‌های `etehadwp.com` (صفحهٔ اصلی، راهنما) و بازارگاه فقط از
  نظر صحت رشته بررسی شده‌اند. صفحهٔ راهنما در زمان تحلیل از طریق ابزار متن‌خوان
  باز شد و موجود بود.
- **تست روی هاست واقعی:** انجام نشد؛ چک‌لیست آن در `docs/DEPLOY.md` آمده است.

## ۴. تصمیم‌های کیفیتی که آگاهانه گرفته شدند

- **هیچ تصویر ساختگی جای اسکرین‌شات واقعی نگذاشته شد.** قاب‌ها خالی‌اند و مسیر
  فایل مورد انتظار را نشان می‌دهند.
- **هیچ قیمت/امتیاز/نظری در HTML یا JSON-LD نیست.** به‌جای آن متغیر پیکربندی و
  نشان «در انتظار اعلام» گذاشته شد.
- **دکمهٔ خرید غیرفعال است، نه لینک‌دار به صفحهٔ اصلی بازارگاه** (که در صفحهٔ فعلی
  وجود دارد و کاربر را به مقصد نامرتبط می‌برد).
- **پیش‌نمایش گفت‌وگو کاملاً آفلاین است** و در سه جای صفحه این موضوع نوشته شده.
- **فونت و همهٔ تصاویر محلی‌اند**؛ هیچ درخواستی به دامنهٔ سوم ارسال نمی‌شود و هیچ
  کد تحلیلی/ردیابی اضافه نشده است.
- **حالت کم‌حرکت (`prefers-reduced-motion`)** و اسکرول نرم خاموش می‌شود.
